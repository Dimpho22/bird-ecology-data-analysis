Wits Campus Bird Ecology Data Analysis

Project Overview

This project analyses bird communities across 28 habitat patches at the University of the Witwatersrand (Wits) in Johannesburg, South Africa. Using bird count observations and R, the analysis explores differences in species counts, variation across habitats, niche breadth, and niche overlap.

The project combines ecological concepts with statistical analysis and data visualisation to investigate patterns in bird distribution across campus habitats.

Objectives

* Compare observed counts across six bird species.
* Examine the distribution of bird counts across habitat patches.
* Calculate descriptive statistics and conduct a chi-square test.
* Estimate niche breadth using Smith’s index.
* Calculate pairwise niche overlap using Pianka’s index.
* Visualise patterns in bird counts and habitat use.

Dataset

The dataset contains observations from 28 habitat patches and six bird species:

* Hadeda ibis
* Rock dove
* Sacred ibis
* Cattle egret
* Egyptian goose
* Indian myna

Zero counts are retained to represent patches where a species was not recorded.

Methods and Analysis

The analysis uses R to reshape and summarise the dataset, calculate descriptive statistics, and generate histograms and boxplots. A chi-square goodness-of-fit test examines whether the observed total counts differ from an equal-count expectation across species.

Smith’s index is used to estimate niche breadth, while Pianka’s index is used to compare patterns of habitat use between species.
